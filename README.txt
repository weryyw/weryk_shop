GRACE STORE — проект с фотобанком для Telegram-бота

В архиве:
- bot.py — обновлённый код бота;
- requirements.txt — зависимости;
- photos/001.jpg ... — 46 фотографий;
- photos_index.jpg — лист с номерами фотографий;
- Каталог.csv — таблица для заполнения карточек.

Как использовать фото:
1. В боте администратор вызывает /photos, чтобы увидеть лист с номерами.
2. Затем /addproduct и проходит обычные шаги добавления товара.
3. На последнем шаге вместо отправки картинки можно ввести номер фото, например 12.

ВАЖНО: названия моделей, цены и размеры не подставлялись автоматически — их нужно подтвердить.
Куртки отображаются как «Скоро здесь появятся новинки».
Кнопка «Отзывы» добавлена в главное меню.

Безопасность:
BOT_TOKEN и ADMIN_ID задаются в переменных окружения Bothost, а не записываются в bot.py.
Создай в настройках бота переменную BOT_TOKEN со значением токена от BotFather,
и ADMIN_ID со своим числовым Telegram ID. Не публикуй токен в GitHub.
